8.1

Circuit Identities

Different circuits can perform the same operation, as \(HZH\) and \(X\) already showed. Rules for recognizing such equalities let us shorten a circuit, and, more usefully, move a gate into the basis where we need it. With them we turn flips into phases, attach a sign to any chosen string, and build a gate that changes every amplitude of a register at once.

8.1.1 When two circuits agree§

\(HZH\) and \(X\) use three gates against one, yet perform the same operation. How do we recognize such coincidences, and use them to shorten a circuit?

A circuit acts linearly, so two circuits are equal when they send every basis string to the same output state, phases included. If the outputs differ by one common factor \(e^{i\gamma}\), no measurement can tell them apart, and we call them equal up to global phase; under a control that factor multiplies one branch only and becomes visible. An equation between two circuits is a circuit identity.

A few identities do most of the work. Gates on different wires can be exchanged. \(X\), \(Z\), \(H\), and CNOT are their own inverses, so two equal ones in a row cancel. Exchanging \(X\) and \(Z\) on one wire changes only the global sign, since \(ZX=-XZ\); for example, \(ZXZ=-X\).

The most useful identities move a gate past a CNOT, and bits show how. An \(X\) on the control turns \(\ket a\ket b\) into \(\ket{a\oplus1}\ket{b\oplus a\oplus1}\) after the CNOT, which is also what the CNOT followed by \(X\) on both wires produces. A \(Z\) on the target attaches \((-1)^b=(-1)^a(-1)^{a\oplus b}\), the sign that \(Z\) on both wires attaches after the CNOT. So

\[\mathrm{CNOT}\,(X\otimes I)=(X\otimes X)\,\mathrm{CNOT},\qquad\mathrm{CNOT}\,(I\otimes Z)=(Z\otimes Z)\,\mathrm{CNOT}.\]

An \(X\) on the target and a \(Z\) on the control pass through unchanged. Simplifying then works as in algebra: move gates until equal ones meet, and cancel. \(X\) on the control, a CNOT, and \(X\) on both wires reduce to the CNOT alone, because the first \(X\) passes through as \(X\otimes X\) and cancels the last.

8.1.2 Turning flips into signs§

Phase kickback turned a CNOT's flip into a sign by preparing the target in \(\ket-\). Can we change the gate instead, so that it attaches the sign itself?

From \(HZH=X\) and \(H^2=I\) we get \(HXH=Z\). With \(H\) on the target before and after a CNOT, the target undergoes \(HIH=I\) when the control is \(0\) and \(HXH=Z\) when it is \(1\):

\[(I\otimes H)\,\mathrm{CNOT}\,(I\otimes H)\ket{a}\ket{b}=(-1)^{ab}\ket{a}\ket{b}.\]

This is the controlled-\(Z\) gate, \(\mathrm{CZ}=\operatorname{diag}(1,1,1,-1)\). Its sign depends only on \(ab\), so CZ is symmetric in its qubits and is drawn as two joined dots. Two identities follow. Hadamards on both wires around a CNOT reverse it: writing the CNOT as \(H\), CZ, \(H\) on its target, the Hadamards on that wire cancel and leave \(H\) around CZ on the other wire. And an \(X\) passes through CZ by leaving a \(Z\) on the other qubit, \(\mathrm{CZ}\,(X\otimes I)=(X\otimes Z)\,\mathrm{CZ}\), since flipping \(a\) changes \((-1)^{ab}\) by \((-1)^b\).

Why does the sandwich work? \(H\) carries \(\ket0,\ket1\) to \(\ket+,\ket-\), which \(X\) multiplies by \(+1\) and \(-1\). In general, if \(U\ket e=\lambda\ket e\), then

\[(VUV^\dagger)\,V\ket e=VU\ket e=\lambda\,V\ket e.\]

Forming \(VUV^\dagger\) is called conjugation of \(U\) by \(V\): the new gate does in the basis \(V\ket0,V\ket1,\dots\) what \(U\) does in the computational basis, at the cost of the gates of \(V\) and \(V^\dagger\).

8.1.3 Marking a string with a phase§

Controlled-\(Z\) attaches a sign to the single string \(11\). A phase oracle that marks one answer must attach the sign to a string \(w\) of our choosing, on any number \(n\) of qubits. Using the matching bit \(m_w(x)\), which is one only when \(x=w\), the gate we want is

\[O_w\ket x=(-1)^{m_w(x)}\ket x.\]

Two moves give it. First, more controls. Write \(C^{n-1}Z\) for the \(n\)-qubit controlled-\(Z\), which multiplies \(\ket{1\cdots1}\) by \(-1\) and leaves every other basis string alone; its sign is \((-1)^{x_1x_2\cdots x_n}\). Conjugating the target of a flip with \(n-1\) controls by \(H\), exactly as for CZ, produces it. We already know how to build that flip from Toffoli gates and a few workspace qubits.

Second, move the sign from \(1\cdots1\) to \(w\). Apply \(X\) to every wire where \(w_j=0\). Call this layer of flips the mask \(M_w\). It sends \(\ket w\) to \(\ket{1\cdots1}\), and it sends every other string to a string other than \(1\cdots1\). The mask is its own inverse, so conjugating by it gives

\[O_w=M_w\,C^{n-1}Z\,M_w.\]

Check the smallest case, two qubits and \(w=01\), where the mask is \(X\) on the first wire. Then \(\ket{01}\to\ket{11}\to-\ket{11}\to-\ket{01}\), so the marked string changes sign. Meanwhile \(\ket{11}\to\ket{01}\to\ket{01}\to\ket{11}\), because the mask moves \(11\) away from the string that CZ marks.

A function \(f\) that equals one on several strings needs a sign on each. Every \(O_w\) is diagonal, so these gates commute, and applying one for each marked string attaches \((-1)^{f(x)}\). This mirrors the row-by-row construction of a bit oracle, and it costs as much: one multi-controlled gate per marked string. When \(f\) has a short circuit, compute, phase, uncompute is cheaper. For a single marked string, the number of gates grows in proportion to \(n\), not to the number \(2^n\) of strings.

8.1.4 Reflection about the uniform state§

The marking gates leave each basis string in place and only multiply it by a sign. What do we get if we conjugate such a gate by \(H^{\otimes n}\), which sends \(\ket{0^n}\) to the uniform state \(\ket s=2^{-n/2}\sum_x\ket x\)?

Take the sign gate that keeps \(\ket{0^n}\) and negates every other string:

\[R_0=2\ketbra{0^n}{0^n}-I.\]

The marking gate for the all-zero string is \(O_{0^n}=I-2\ketbra{0^n}{0^n}\), which negates \(\ket{0^n}\) alone. So \(R_0=-O_{0^n}\). The factor \(-1\) multiplies every amplitude equally and changes no measurement probability, so the circuit \(X^{\otimes n}\,C^{n-1}Z\,X^{\otimes n}\) serves for \(R_0\).

Now conjugate. \(H^{\otimes n}\) is its own inverse and its own adjoint, so \(H^{\otimes n}\ket{0^n}=\ket s\) and \(\bra{0^n}H^{\otimes n}=\bra s\). Then

\[D=H^{\otimes n}R_0H^{\otimes n}=2\ketbra ss-I.\]

By the conjugation rule, \(D\) does to \(\ket s\) what \(R_0\) does to \(\ket{0^n}\): it keeps it, since \(D\ket s=2\ket s-\ket s=\ket s\). Every state orthogonal to \(\ket s\) has zero overlap with it, so \(D\) multiplies such a state by \(-1\). A gate that keeps one direction and reverses every perpendicular direction is a reflection, here about the line through \(\ket s\).

This gate differs in kind from the marking gates. With \(N=2^n\), its matrix entries are \(\bra xD\ket y=2/N\) for \(x\neq y\) and \(2/N-1\) for \(x=y\). No entry is zero, so \(D\) changes every amplitude of the register at once. Yet its circuit uses \(2n\) Hadamards, \(2n\) bit flips, and one multi-controlled \(Z\). An operation with \(N^2\) nonzero entries costs a number of gates proportional to \(n\). Paired with the phase oracle \(O_w\), this reflection is the step that quantum search repeats.

The construction carries two caveats. The circuit implements \(-D\), not \(D\); the sign is unobservable as long as the reflection is not itself controlled by another qubit. And nothing used a special property of \(H^{\otimes n}\) beyond its preparing \(\ket s\) from \(\ket{0^n}\). Any preparation circuit \(A\) gives the reflection \(AR_0A^\dagger\) about the state \(A\ket{0^n}\).

8.2

Controlled Gates

Every construction so far rests on gates with two or more controls: the Toffoli gate, the multi-controlled flips built from it, and the multi-controlled \(Z\). A device applies gates to one or two qubits at a time. Diagonal gates multiply by adding their phases, so controlled phases come first. Conjugation then extends them to a controlled version of any one-qubit gate, and the same addition of exponents removes the need for a second control.

8.2.1 Controlled phase gates§

Controlled-\(Z\) attaches \(-1\) to \(\ket{11}\). Can we attach any phase \(e^{i\phi}\) instead? That is, can we build the controlled phase gate \(\operatorname{diag}(1,1,1,e^{i\phi})\) from CNOTs and the one-qubit phase gates \(R_\theta=\operatorname{diag}(1,e^{i\theta})\)?

Follow a basis state \(\ket a\ket b\) through such a circuit. A phase gate \(R_\theta\) on a wire that holds the bit \(c\) multiplies the state by \(e^{i\theta c}\). A CNOT changes which bits the wires hold but attaches no phase. So the circuit multiplies \(\ket a\ket b\) by \(e^{i\Theta}\), where \(\Theta\) adds up \(\theta c\) over all its phase gates, each using the bit on its wire at that moment.

With phase gates alone, \(\Theta=\theta_1a+\theta_2b\) is a weighted sum of the bits. We need \(\Theta=\phi\,ab\), a product. A CNOT from the first wire to the second puts \(a\oplus b\) on the second wire, where a phase gate contributes a multiple of \(a\oplus b\). Is the product a combination of \(a\), \(b\), and \(a\oplus b\)? Checking the four cases shows

\[a\oplus b=a+b-2ab,\qquad\text{so}\qquad ab=\tfrac12\bigl(a+b-(a\oplus b)\bigr).\]

The circuit follows. Apply \(R_{\phi/2}\) to both wires, then a CNOT, then \(R_{-\phi/2}\) to the second wire, then a second CNOT that restores \(b\). The total phase is \(\tfrac\phi2\bigl(a+b-(a\oplus b)\bigr)=\phi\,ab\). For \(\ket{11}\) it is \(\tfrac\phi2+\tfrac\phi2-0=\phi\); for \(\ket{10}\) it is \(\tfrac\phi2+0-\tfrac\phi2=0\); for \(\ket{00}\) every term vanishes.

Two angles recur. The quarter turn \(S=R_{\pi/2}=\operatorname{diag}(1,i)\) and the eighth turn \(T=R_{\pi/4}=\operatorname{diag}(1,e^{i\pi/4})\) satisfy \(T^2=S\) and \(S^2=Z\). With \(\phi=\pi\), the circuit uses \(S\), \(S\), and \(S^\dagger\) and gives CZ again. With \(\phi=\pi/2\), it builds controlled-\(S\) from \(T\), \(T\), and \(T^\dagger\). Moving a phase under a control halves its angle, and that is where \(T\) enters.

8.2.2 Controlled one-qubit gates§

Now take a gate that is not diagonal, such as \(H\), and ask for controlled-\(U\): apply \(U\) to the target when the control is \(1\), and nothing otherwise. Conjugation turned CNOT into CZ. Can it turn controlled-\(U\) into a controlled phase?

It can if there are two perpendicular states that \(U\) only multiplies by phases, as \(X\) does with \(\ket+\) and \(\ket-\). We take the existence of such a pair from linear algebra.

Assumption. For every one-qubit unitary \(U\) there are orthonormal states \(\ket{e_0}\) and \(\ket{e_1}\) and real angles \(\alpha\) and \(\beta\) with \(U\ket{e_0}=e^{i\alpha}\ket{e_0}\) and \(U\ket{e_1}=e^{i\beta}\ket{e_1}\).

Such states are called eigenvectors of \(U\), as for \(X\). Let \(W\) be the one-qubit gate with \(W\ket0=\ket{e_0}\) and \(W\ket1=\ket{e_1}\). Then \(U=W\Lambda W^\dagger\) with \(\Lambda=\operatorname{diag}(e^{i\alpha},e^{i\beta})\), because both sides do the same thing to \(\ket{e_0}\) and \(\ket{e_1}\).

Conjugate only the target. When the control is \(0\), the target undergoes \(WW^\dagger=I\); when it is \(1\), the target undergoes \(W\Lambda W^\dagger=U\). So controlled-\(U\) is controlled-\(\Lambda\) between \(W^\dagger\) and \(W\) on the target wire.

Controlled-\(\Lambda\) multiplies \(\ket c\ket t\) by \(e^{i\alpha}\) when \(c=1,t=0\) and by \(e^{i\beta}\) when \(c=1,t=1\). Its phase is therefore \(\alpha c+(\beta-\alpha)ct\). The first term is the phase gate \(R_\alpha\) on the control wire; the second is the controlled phase gate with angle \(\beta-\alpha\). Altogether,

\[\text{controlled-}U=(I\otimes W)\,\bigl(\text{controlled-}R_{\beta-\alpha}\bigr)\,(R_\alpha\otimes I)\,(I\otimes W^\dagger),\]

which uses two CNOTs and a handful of one-qubit gates. For \(U=X\), the eigenvectors \(\ket+\) and \(\ket-\) give \(W=H\), \(\alpha=0\), and \(\beta=\pi\), and the formula returns \(H\,\mathrm{CZ}\,H\) on the target: the CNOT we began with.

One term deserves attention. Replace \(U\) by \(e^{i\gamma}U\). Alone, the two gates are indistinguishable. Controlled, both angles grow by \(\gamma\), and the extra \(R_\gamma\) on the control multiplies the control-\(1\) branch relative to the control-\(0\) branch. A global phase of \(U\) becomes a relative phase once \(U\) is controlled.

8.2.3 Two controls from one§

The Toffoli gate flips its target when both controls are \(1\), and every multi-controlled flip we used was built from Toffolis. Can a gate with two controls be built from gates with one?

The controlled phase gate added exponents: a phase proportional to \(a+b-(a\oplus b)\) equals one proportional to \(ab\). Powers of a single gate add in the same way, since \(V^jV^k=V^{j+k}\). So choose \(V\) with \(V^2=U\) and try to apply \(V\) to the target \(b\) times, \(V^\dagger=V^{-1}\) another \(a\oplus b\) times, and \(V\) a further \(a\) times. The target would undergo

\[V^{\,b-(a\oplus b)+a}=V^{2ab}=U^{ab},\]

which is \(U\) exactly when \(a=b=1\). Because all the factors are powers of \(V\), their order on the target does not matter.

Each factor is a gate with one control. Controlled-\(V\) from wire \(b\) supplies \(V^b\). A CNOT from \(a\) to \(b\) makes wire \(b\) hold \(a\oplus b\), so controlled-\(V^\dagger\) from that wire supplies \(V^{-(a\oplus b)}\), and a second CNOT restores \(b\). Controlled-\(V\) from wire \(a\) supplies \(V^a\). Five two-qubit gates in all. Check the case \(a=1,b=0\): the first gate does nothing, wire \(b\) becomes \(1\) and \(V^\dagger\) acts, then \(b\) returns to \(0\) and \(V\) acts. The target undergoes \(VV^\dagger=I\), as it should.

A square root \(V\) always exists: with \(U=W\Lambda W^\dagger\), halve both phases of \(\Lambda\). For the Toffoli gate the cheapest route goes through phases. Take \(U=Z\) and \(V=S\), since \(S^2=Z\). The construction gives the doubly controlled \(Z\), which multiplies \(\ket{111}\) by \(-1\). Conjugating its target by \(H\) gives the Toffoli gate, and each controlled-\(S\) or controlled-\(S^\dagger\) needs two CNOTs and three \(T\) or \(T^\dagger\) gates. The result uses only CNOT, \(H\), \(T\), and \(T^\dagger\): eight CNOTs and nine \(T\)-type gates as built here. A more careful arrangement uses six CNOTs and seven \(T\)-type gates.

That settles every gate the oracle constructions used. A flip with \(n\) controls was built from Toffolis and workspace. A controlled-\(U\) with \(n\) controls is built the same way: compute the AND of the controls into a workspace qubit, apply controlled-\(U\) from that qubit, and uncompute. Every multi-controlled gate therefore reduces to CNOT and one-qubit gates, with a number of gates proportional to \(n\).

8.3

Universal Gate Sets

We can now build any one-qubit gate with any number of controls from CNOT and one-qubit gates. An arbitrary unitary on \(n\) qubits is not of that form. We therefore break such a unitary into pieces that each touch only two basis strings, build each piece as a controlled gate, and then count how many gates the whole costs. Real machines offer only finitely many gates, so exact construction gives way to approximation.

8.3.1 Two-level unitaries§

What must a gate set contain to build every unitary? Gates acting on separate wires never turn a product state into an entangled one. CNOT, Toffoli, and \(X\) only reorder basis strings, so from \(\ket{0^n}\) they never produce a superposition. We need both kinds. Suppose we have them: how do we assemble an arbitrary unitary \(U\) on \(N=2^n\) basis strings?

Look first at the simplest unitaries that are not one-qubit gates: those that act on just two basis strings \(j\) and \(k\), mixing their amplitudes by a \(2\times2\) unitary, and leave every other string alone. These are called two-level unitaries. For example, \(H\otimes I\) on two qubits mixes \(00\) with \(10\), and separately \(01\) with \(11\); it is the product of two two-level unitaries.

Every unitary is a product of two-level ones. To see this, clear the first column of \(U\) one entry at a time. Its first entry is \(p\) and some later entry is \(q\). With \(r=\sqrt{|p|^2+|q|^2}\), the two-level unitary that acts on those two coordinates by

\[G=\frac1r\begin{pmatrix}\bar p&\bar q\\-q&p\end{pmatrix},\qquad G\begin{pmatrix}p\\q\end{pmatrix}=\begin{pmatrix}r\\0\end{pmatrix},\]

replaces \(q\) by \(0\). Its rows are orthonormal, so it is unitary. (If \(q=0\) already, skip this step.) Applying such a step for each later entry leaves the first column equal to \((r,0,\dots,0)\). A unitary preserves length, and the column had length one, so now \(r=1\).

The rows of a unitary also have length one. The first row now begins with \(1\), so the rest of that row must be zero. What remains is a unitary on the other \(N-1\) basis strings, and we repeat. At most \((N-1)+(N-2)+\dots+1=N(N-1)/2\) steps reduce \(U\) to \(I\), possibly with one leftover phase on the last basis string. Undoing the steps in reverse order writes \(U\) as a product of their inverses, which are again two-level unitaries.

8.3.2 Universality of CNOT and one-qubit gates§

A two-level unitary mixes two basis strings \(a\) and \(b\) and fixes all others. How do we build it from the controlled gates we have?

Suppose first that \(a\) and \(b\) differ in exactly one bit, at position \(j\). Then the gate is a one-qubit gate \(\tilde U\) on wire \(j\), applied only when the other wires hold the bits that \(a\) and \(b\) share. That is a multi-controlled \(\tilde U\), with \(X\) gates around each control wire whose required bit is \(0\), the same masks used for marking a string. For \(H\otimes I\), the pair \(00,10\) differs only in the first bit, with the second bit \(0\); the pair \(01,11\) differs in the first bit, with the second bit \(1\). So \(H\otimes I\) is controlled-\(H\) on the first wire with a masked control, followed by controlled-\(H\) with an ordinary control. The two together apply \(H\) whatever the second bit is.

If \(a\) and \(b\) differ in several bits, flip those bits one at a time. This gives a chain of strings \(a=g_0,g_1,\dots,g_m=b\) in which neighbours differ in one bit, called a Gray code. A multi-controlled \(X\) exchanges the amplitudes of two neighbours. Exchanging \(g_m\) with \(g_{m-1}\), then \(g_{m-1}\) with \(g_{m-2}\), and so on down to \(g_1\), moves the amplitude of \(b\) to \(g_1\), which differs from \(a\) in one bit. Apply the one-bit case to \(a\) and \(g_1\), then undo the exchanges. Since \(m\le n\), this uses fewer than \(2n\) multi-controlled gates.

Combining the steps: every unitary is a product of two-level unitaries; every two-level unitary is a product of multi-controlled one-qubit gates; and every multi-controlled gate is a product of CNOTs and one-qubit gates. Hence CNOT together with all one-qubit gates builds every unitary on any number of qubits exactly. A gate set with this property is called universal.

The argument rests on the assumption that every one-qubit unitary has an orthonormal pair of eigenvectors, and on arbitrary one-qubit gates being available. Neither CNOT nor the one-qubit gates suffice alone: one cannot create superpositions from basis states, and the other cannot entangle. Together they can build anything.

Further detail: Barenco et al.: Elementary gates for quantum computation.

8.3.3 The cost of a generic unitary§

How many gates did that construction spend? Up to \(N(N-1)/2\) two-level unitaries, each needing up to \(2n\) multi-controlled gates of about \(n\) elementary gates each. With \(N=2^n\), that is of order \(n^2 4^n\) gates, growing exponentially in \(n\). Is that a defect of our construction, or must most unitaries cost that much?

Count the numbers needed to specify a unitary. An \(N\times N\) matrix has \(N^2\) complex entries, or \(2N^2\) real numbers. Each column must have length one: \(N\) real conditions. Each of the \(N(N-1)/2\) pairs of columns must be orthogonal: one complex condition, or two real ones, per pair. That leaves

\[2N^2-N-N(N-1)=N^2\]

free real numbers. An overall phase changes no prediction, so \(N^2-1=4^n-1\) of them matter.

A circuit has fewer dials. With \(N=2\), the same count shows that a one-qubit gate has \(3\) numbers that matter; a CNOT has none. Which gates go on which wires is a discrete choice with finitely many options for a given circuit length. So circuits of \(L\) gates offer at most \(3L\) adjustable real numbers in each arrangement.

We use one further fact. Assumption. A smooth assignment from \(k\) real numbers to unitaries cannot cover a region of unitaries described by more than \(k\) independent real numbers. Covering every unitary on \(n\) qubits therefore needs \(3L\ge4^n-1\), so

\[L\ \ge\ \frac{4^n-1}{3}.\]

Universality says every unitary can be built; it does not say cheaply. Almost every unitary on \(n\) qubits needs a number of gates that grows exponentially in \(n\), whatever the construction. Useful algorithms are built from the rare unitaries with short circuits, such as the phase oracle and the reflection, which need a number of gates proportional to \(n\).

8.3.4 Finite gate sets and approximation§

Universality used arbitrary one-qubit gates, with a continuum of angles. A machine, especially one that protects its qubits against errors, applies a fixed finite set of gates. What can a finite set build?

Not everything exactly. With finitely many gates there are finitely many circuits of each length, so the circuits can be listed one after another. The phase gates \(R_\theta\) alone, one for each real angle, cannot be so listed. Most unitaries therefore have no exact circuit, and we must ask for approximations.

How close is close enough? Measure the distance between the ideal unitary \(U\) and a circuit \(V\) by the largest change in any output state,

\[\|U-V\|=\max_{\|\psi\|=1}\bigl\|(U-V)\ket\psi\bigr\|,\]

the operator-norm error. If \(\|U-V\|\le\epsilon\), then every outcome probability changes by at most \(2\epsilon\). Write \(u=\braket{y}{U\psi}\) and \(v=\braket{y}{V\psi}\). Then \(|u-v|\le\epsilon\), and

\[\bigl||u|^2-|v|^2\bigr|=\bigl||u|-|v|\bigr|\,\bigl(|u|+|v|\bigr)\le|u-v|\cdot2\le2\epsilon.\]

How do errors combine along a circuit? Suppose gates \(U_1,U_2\) are replaced by \(V_1,V_2\). Adding and subtracting \(V_2U_1\),

\[V_2V_1-U_2U_1=V_2(V_1-U_1)+(V_2-U_2)U_1.\]

Unitaries preserve length, so the error is at most \(\|V_1-U_1\|+\|V_2-U_2\|\). By induction, the errors of \(L\) gates add up at most linearly. Building each gate to accuracy \(\epsilon/L\) keeps the whole circuit within \(\epsilon\). Two gates that differ by a global phase should be compared after matching that phase, unless the gate is used under a control, where the phase becomes relative.

Which finite set? The Toffoli construction used only CNOT, \(H\), \(T\), and \(T^\dagger=T^7\). The set \(\{H,S,\mathrm{CNOT},T\}\) is called Clifford+T. Without \(T\), circuits of \(H\), \(S\), and CNOT reach only finitely many one-qubit gates up to phase, and they can be simulated efficiently on a classical computer. Adding \(T\) makes every one-qubit gate approachable. We quote the guarantee of how quickly.

Theorem (Solovay–Kitaev). Every one-qubit gate can be approximated to operator-norm error \(\delta\) by a sequence of \(H\) and \(T\) gates of length proportional to \(\log^c(1/\delta)\), for a fixed constant \(c\).

Combining the two results, a circuit of \(L\) CNOTs and arbitrary one-qubit gates can be approximated to accuracy \(\epsilon\) with a number of Clifford+T gates proportional to \(L\log^c(L/\epsilon)\). Passing to a finite gate set multiplies the cost by a slowly growing factor; it does not change exponential cost into polynomial, or the reverse.

8.4

Physical Constraints

The circuit model lets any two wires interact, and so far every gate has been exact or approximated on paper. Devices allow interactions only between neighbouring qubits, and they apply every gate slightly wrongly. Neither fact changes what can be computed; both change the cost. We first count the cost of moving qubits, then ask how an error can be removed rather than merely bounded.

8.4.1 Connectivity and SWAP§

On paper, a CNOT joins any two wires. On a chip, two-qubit gates act only between qubits that are physically coupled, a pattern called the device's connectivity. How do we apply a CNOT between two qubits that are not coupled?

We move a state instead. The SWAP gate exchanges two qubits: \(\ket a\ket b\mapsto\ket b\ket a\). Three CNOTs in alternating directions build it. Starting from \(\ket a\ket b\), a CNOT from the first wire to the second gives \(\ket a\ket{a\oplus b}\). A CNOT from the second to the first gives \(\ket{a\oplus(a\oplus b)}\ket{a\oplus b}=\ket b\ket{a\oplus b}\). A third CNOT from the first to the second gives \(\ket b\ket{b\oplus a\oplus b}=\ket b\ket a\). This holds on every basis state, so by linearity SWAP exchanges any two-qubit state, entangled or not.

On a line of qubits, two qubits at distance \(d\) become neighbours after \(d-1\) swaps, so one long-range CNOT costs about \(3(d-1)\) extra CNOTs. A compiler can often leave the moved qubit in its new place rather than swap it back, keeping track of where each logical qubit now sits. Gates on all \(n\) wires, such as the multi-controlled \(Z\) in the reflection, pay this overhead repeatedly. Connectivity does not change what a circuit computes, but it multiplies gate count and depth.

8.4.2 Correcting bit flips§

Errors add up at most linearly: \(L\) gates, each off by \(\epsilon\), give an error of at most \(L\epsilon\). A long computation needs \(L\epsilon\) small, which hardware alone cannot supply. Can errors be removed during the computation, rather than merely bounded?

Classically we would store three copies, \(0\mapsto000\) and \(1\mapsto111\), and take a majority vote. Two obstacles seem to block this. An unknown state \(a\ket0+b\ket1\) cannot be copied. And reading the copies would collapse the superposition.

Copying is not needed. Two CNOTs from the data qubit onto two qubits starting in \(\ket0\) give

\[a\ket0+b\ket1\ \longmapsto\ a\ket{000}+b\ket{111}.\]

This is not three copies of the state, which would be \((a\ket0+b\ket1)^{\otimes3}\) with eight terms. It is one qubit of information spread over three qubits. Suppose \(X\) now strikes the second qubit, giving \(a\ket{010}+b\ket{101}\). How do we find the flipped qubit without learning \(a\) or \(b\)?

Ask only whether neighbours agree. In both branches, qubits \(1\) and \(2\) disagree, and so do qubits \(2\) and \(3\). CNOTs from qubits \(1\) and \(2\) onto a fresh qubit in \(\ket0\) write \(x_1\oplus x_2\) there; two more CNOTs write \(x_2\oplus x_3\) onto a second fresh qubit. Measuring these two qubits gives \((1,1)\) with certainty, because both branches have the same parities. The measurement therefore leaves \(a\ket{010}+b\ket{101}\) intact. The measured pair is called the syndrome: \((0,0)\) means no flip, \((1,0)\) means qubit \(1\), \((1,1)\) qubit \(2\), and \((0,1)\) qubit \(3\). Applying \(X\) to the indicated qubit restores \(a\ket{000}+b\ket{111}\).

Errors need not be whole flips. Suppose the second qubit is rotated slightly, by \(R_x(\theta)=\cos\tfrac\theta2I-i\sin\tfrac\theta2X\). The state becomes

\[\cos\tfrac\theta2\bigl(a\ket{000}+b\ket{111}\bigr)-i\sin\tfrac\theta2\bigl(a\ket{010}+b\ket{101}\bigr).\]

The two parts have different syndromes. Measuring the syndrome gives \((0,0)\) with probability \(\cos^2\tfrac\theta2\), leaving the correct state, or \((1,1)\) with probability \(\sin^2\tfrac\theta2\), leaving a whole flip on qubit \(2\) that we then undo. Either way the encoded state is restored. Measuring the syndrome turns a continuous error into one of finitely many flips.

This code has clear limits. Two flips produce a syndrome that points to the wrong qubit, and the correction then completes a logical error. A \(Z\) on any qubit turns \(a\ket{000}+b\ket{111}\) into \(a\ket{000}-b\ket{111}\), which has the same parities, so this code cannot see it. Correcting both kinds of error, and correcting errors in the correction circuit itself, requires larger codes. The principle stays the same: measure only which error occurred, never the encoded amplitudes.
