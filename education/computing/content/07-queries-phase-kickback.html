7.1

Phase Kickback

If a quantum circuit evaluates a function \(f\) by writing \(f(x)\) into an answer qubit, the input and answer registers generally become entangled. Before we can make different input branches interfere, we need a way to store \(f(x)\) in the relative phases of the input register while leaving the target qubit untouched.

7.1.1 Reversible quantum oracles§

Suppose we are given access to a Boolean function \(f:\{0,1\}\to\{0,1\}\) as a black-box operation whose internal circuit is hidden. A naive map \(\ket{x}\mapsto\ket{f(x)}\) cannot be a quantum gate whenever \(f\) is constant, because it sends two orthogonal inputs \(\ket{0}\) and \(\ket{1}\) to the same output state and therefore cannot be inverted. Overwriting a second wire via \(\ket{x}\ket{y}\mapsto\ket{x}\ket{f(x)}\) likewise erases \(y\) and fails unitarity.

To grant a quantum circuit coherent access to \(f\), we embed it into a reversible two-qubit oracle \(U_f\) acting on an input wire \(\ket{x}\) and a target wire \(\ket{y}\) by addition modulo \(2\):

\[U_f\ket{x}\ket{y} = \ket{x}\ket{y\oplus f(x)},\qquad x,y\in\{0,1\}.\]

Because \(U_f\) permutes orthonormal basis states and equals its own inverse (\(U_f^2=I\)), it is unitary; each execution counts as one quantum query. Notice how \(U_f\) acts on the target wire for a fixed basis input \(\ket{x}\): it applies the identity \(I\) if \(f(x)=0\) and the bit flip \(X\) if \(f(x)=1\), so \(U_f\ket{x}\ket{y} = \ket{x}\otimes X^{f(x)}\ket{y}\). When the target starts in \(\ket{0}\), this writes \(f(x)\) directly into the target bit, entangling it with \(\ket{x}\) whenever \(f\) is non-constant. Can a different choice of target state avoid entanglement altogether?

7.1.2 Bit-flip eigenstates and phase kickback§

Because \(U_f\) acts on the target as \(X^{f(x)}\), the target avoids becoming entangled with \(\ket{x}\) if it starts in an eigenstate of \(X\)—a state that \(X\) leaves unchanged up to a scalar factor. Testing the diagonal basis states \(\ket{\pm} = (\ket{0}\pm\ket{1})/\sqrt{2}\) gives

\[X\ket{+} = +\ket{+},\qquad X\ket{-} = -\ket{-}.\]

Preparing the target in \(\ket{+}\) keeps it unentangled, yet erases \(f(x)\) completely because \(X^{f(x)}\ket{+} = \ket{+}\) for both \(f(x)=0\) and \(f(x)=1\). Preparing the target in \(\ket{-} = H\ket{1}\), however, produces an eigenvalue that depends on \(f(x)\): \(X^{f(x)}\ket{-} = (-1)^{f(x)}\ket{-}\). Because a scalar factor commutes across the tensor product, the action of \(U_f\) on any basis input \(\ket{x}\) factors as

\[U_f\ket{x}\ket{-} = \ket{x}\otimes X^{f(x)}\ket{-} = (-1)^{f(x)}\ket{x}\ket{-}.\]

The target qubit exits in the exact same state \(\ket{-}\) regardless of \(x\), while the function value \(f(x)\) is transferred onto the input wire as the sign \((-1)^{f(x)}\). This transfer of an eigenvalue from the target onto the control register is called phase kickback.

7.1.3 Phase oracles in superposition§

Phase kickback becomes useful when the input wire is in a superposition. By linearity, feeding \(\ket{+} = (\ket{0}+\ket{1})/\sqrt{2}\) into the input wire alongside \(\ket{-}\) on the target wire turns \(U_f\) into a phase oracle that encodes \(f(0)\) and \(f(1)\) into the relative sign between \(\ket{0}\) and \(\ket{1}\):

\[U_f(\ket{+}\otimes\ket{-}) = \left(\frac{(-1)^{f(0)}\ket{0} + (-1)^{f(1)}\ket{1}}{\sqrt{2}}\right)\otimes\ket{-} = (-1)^{f(0)}\left(\frac{\ket{0} + (-1)^{f(0)\oplus f(1)}\ket{1}}{\sqrt{2}}\right)\otimes\ket{-}.\]

For a general \(n\)-bit function \(f:\{0,1\}^n\to\{0,1\}\), one query on a uniform input superposition produces \(\bigl(2^{-n/2}\sum_x (-1)^{f(x)}\ket{x}\bigr)\otimes\ket{-}\). The target qubit remains completely unentangled in \(\ket{-}\), while the entire truth table of \(f\) is encoded in the signs of the input amplitudes.

7.1.4 Coherent uncomputation§

When a function \(f(x)\) is built from a multi-gate reversible circuit \(A\) that uses temporary workspace qubits starting in \(\ket{0}^{\otimes n}\), we can still obtain a clean phase oracle by applying \(Z\) to the answer qubit and running \(A^\dagger\) in reverse:

\[\ket{x}\ket{0}\ket{0}^{\otimes n} \;\xrightarrow{\ A\ }\; \ket{x}\ket{f(x)}\ket{g(x)} \;\xrightarrow{\ Z_{\text{ans}}\ }\; (-1)^{f(x)}\ket{x}\ket{f(x)}\ket{g(x)} \;\xrightarrow{\ A^\dagger\ }\; (-1)^{f(x)}\ket{x}\ket{0}\ket{0}^{\otimes n}.\]

This three-step compute, phase, uncompute pattern erases both the answer bit and any intermediate workspace garbage \(g(x)\) back to \(\ket{0}\ket{0}^{\otimes n}\), leaving the input register with the pure phase transformation \(\ket{x}\mapsto (-1)^{f(x)}\ket{x}\) and zero entanglement to the auxiliary qubits.

7.2

Global Properties

With \(f(x)\) cleanly encoded in relative phases, we now turn to the kinds of computational problems this encoding is built to solve: extracting collective features of \(f\) across its domain, and understanding why phase storage succeeds where bit storage fails.

7.2.1 Collective features of a function§

Many computational problems do not ask for the individual truth-table value \(f(x)\) at a particular input; instead, they ask for a single summary fact determined by how the outputs \(f(x)\) relate across the entire domain. Such a collective feature is called a global property of \(f\). Examples include:

  • Constant vs. balanced (promise problem): Under the promise that \(f:\{0,1\}^n\to\{0,1\}\) is either constant (identical for every \(x\)) or balanced (outputting \(0\) on half the inputs and \(1\) on the other half), decide which class \(f\) belongs to. For \(n=1\), \((0,0)\) and \((1,1)\) are constant, whereas \((0,1)\) and \((1,0)\) are balanced.
  • Parity and hidden linear structure: Determine \(f(0)\oplus f(1)\), or more generally recover a hidden bitstring \(s\) when \(f(x) = s\cdot x \pmod 2\) (the Bernstein–Vazirani problem).
  • Satisfiability and marked-item search: Decide whether any input \(x\) satisfies \(f(x)=1\), or locate such a marked input (Chapter 9).
  • Periodicity: Find a hidden period \(r\) such that \(f(x+r)=f(x)\) across the domain, which forms the core of quantum order finding and factoring.

7.2.2 Classical query complexity§

To compare classical and quantum algorithms fairly, we work in the black-box query model and count how many evaluations of \(f\) an algorithm requires. Consider deciding whether \(f:\{0,1\}\to\{0,1\}\) is constant or balanced. A deterministic classical algorithm that queries only \(f(0)\) learns a single value: if \(f(0)=0\), both \((0,0)\) (constant) and \((0,1)\) (balanced) remain possible. Even a randomized one-query strategy cannot beat probability \(1/2\) on the worst-case input.

Hence \(2\) classical queries are both necessary and sufficient for \(n=1\). For \(n\)-bit functions under the constant-or-balanced promise, an adversary can return \(0\) on the first \(2^{n-1}\) distinct queries, forcing any deterministic classical algorithm to make \(2^{n-1}+1\) queries in the worst case.

7.2.3 Why bit storage blocks interference§

To see why phase kickback from Section 7.1 is indispensable for global properties, consider what happens if we instead evaluate \(U_f\) on a blank target \(\ket{0}\) and apply Hadamard gates to recombine the input branches. For a two-bit function \(f:\{0,1\}^2\to\{0,1\}\), the circuit \(\ket{00}\ket{0} \xrightarrow{H\otimes H\otimes I} \frac{1}{2}\sum_x\ket{x}\ket{0} \xrightarrow{U_f} \frac{1}{2}\sum_x\ket{x}\ket{f(x)} \xrightarrow{H\otimes H\otimes I} \ket{\psi_3}\) sends amplitude \(\tfrac{1}{4}\) from every input \(\ket{x}\) toward \(\ket{00}\), since \((H\otimes H)\ket{x} = \tfrac{1}{2}\sum_z (-1)^{x\cdot z}\ket{z}\).

When \(f(x)=c\) is constant, the target factors out cleanly as \(\ket{c}\), so all four branches arrive at the identical joint state \(\ket{00}\ket{c}\) and exhibit constructive interference with total amplitude \(4\times\tfrac{1}{4}=1\). When \(f\) is non-constant—for example, \(f(x_1,x_2)=x_1\land x_2\)—the target entangles with the input:

\[\ket{\psi_2} = \frac{\ket{00}+\ket{01}+\ket{10}}{2}\otimes\ket{0} + \frac{\ket{11}}{2}\otimes\ket{1}.\]

After \(H\otimes H\), the three \(f(x)=0\) branches combine into \(\tfrac{3}{4}\ket{00}\ket{0}\), while the \(11\) branch lands in \(\tfrac{1}{4}\ket{00}\ket{1}\). Because \(\braket{0|1}=0\), the target acts as a which-path record that prevents the two groups from interfering, yielding probability \((3/4)^2+(1/4)^2 = 5/8\) instead of coherent cancellation. Phase kickback removes this barrier: keeping the target in \(\ket{-}\) leaves no which-path record, so the input branches interfere freely.

7.3

Deutsch’s Algorithm

Combining phase kickback from Section 7.1 with Hadamard interference for global properties from Section 7.2 gives Deutsch’s algorithm: a one-query quantum procedure that decides whether \(f:\{0,1\}\to\{0,1\}\) is constant or balanced.

7.3.1 State preparation and phase-oracle query§

Start two qubits in \(\ket{0}\ket{1}\) and apply \(H\otimes H\) to prepare \(\ket{+}\ket{-}\). A single query to \(U_f\) then triggers phase kickback, embedding \(f(0)\) and \(f(1)\) into the input amplitudes while leaving the target unentangled in \(\ket{-}\):

\[\ket{0}\ket{1} \;\xrightarrow{\ H\otimes H\ }\; \ket{+}\ket{-} \;\xrightarrow{\ U_f\ }\; \left(\frac{(-1)^{f(0)}\ket{0} + (-1)^{f(1)}\ket{1}}{\sqrt{2}}\right)\otimes\ket{-}.\]

If we measured the input qubit right now, outcomes \(0\) and \(1\) would each appear with probability \(1/2\) for every function \(f\). To convert the relative phase between \(\ket{0}\) and \(\ket{1}\) into a distinguishable computational-basis outcome, we must interfere the two branches.

7.3.2 Interference and single-shot readout§

Applying a final Hadamard gate \(H\) to the input qubit maps \(\ket{+}\to\ket{0}\) and \(\ket{-}\to\ket{1}\):

\[\left(\frac{(-1)^{f(0)}\ket{0} + (-1)^{f(1)}\ket{1}}{\sqrt{2}}\right)\otimes\ket{-} \;\xrightarrow{\ H\otimes I\ }\; (-1)^{f(0)}\ket{f(0)\oplus f(1)}\otimes\ket{-}.\]

Measuring the input qubit in the computational basis returns \(0\) with certainty when \(f\) is constant (\(f(0)=f(1)\)) and \(1\) with certainty when \(f\) is balanced (\(f(0)\neq f(1)\)). The individual value \(f(0)\) survives only as an unobservable global sign \((-1)^{f(0)}\): Deutsch’s algorithm trades knowledge of individual entries for the global bit \(f(0)\oplus f(1)\).

7.3.3 Query separation and Deutsch–Jozsa§

Deutsch’s algorithm uses one quantum query where an exact classical procedure needs two. The same interference calculation extends to a Boolean function \(f:\{0,1\}^n\to\{0,1\}\), with \(n\geq1\), promised to be either constant or balanced. Constant means that every input has the same output; balanced means that exactly half the inputs give each output. The Deutsch–Jozsa algorithm decides between these two cases.

Start with \(n\) input qubits and one target qubit, in that order. Write \(0^n\) for the all-zero input string. Applying a Hadamard to every qubit prepares a uniform input superposition and the target state needed for phase kickback:

\[\begin{aligned} \ket{\psi_0}&=\ket{0^n}\ket{1},\\ \ket{\psi_1}&=(H^{\otimes n}\otimes H)\ket{\psi_0} =\frac{1}{\sqrt{2^n}}\sum_{x\in\{0,1\}^n}\ket{x}\ket{-},\\ \ket{\psi_2}&=U_f\ket{\psi_1} =\frac{1}{\sqrt{2^n}}\sum_x(-1)^{f(x)}\ket{x}\ket{-}. \end{aligned}\]

The query changes signs but leaves every input equally likely if measured now. To combine those signs, apply another Hadamard to each input qubit, leaving the target alone. For a single bit, \(H\ket{x_j}=(\ket{0}+(-1)^{x_j}\ket{1})/\sqrt{2}\). Thus a contribution to output string \(z=z_1\cdots z_n\) acquires one factor \((-1)^{x_jz_j}\) from each wire:

\[H^{\otimes n}\ket{x} =\bigotimes_{j=1}^n\frac{\ket{0}+(-1)^{x_j}\ket{1}}{\sqrt{2}} =\frac{1}{\sqrt{2^n}}\sum_{z\in\{0,1\}^n}(-1)^{x\cdot z}\ket{z}, \qquad x\cdot z=x_1z_1\oplus\cdots\oplus x_nz_n.\]

Here \(x\cdot z\) is the parity of the positions where both strings have a one. Substituting this expansion and collecting all paths that reach the same output gives

\[\begin{aligned} \ket{\psi_3}&=(H^{\otimes n}\otimes I)\ket{\psi_2}\\ &=\frac{1}{2^n}\sum_x\sum_z(-1)^{f(x)+x\cdot z}\ket{z}\ket{-}\\ &=\left(\sum_z A(z)\ket{z}\right)\otimes\ket{-}, \qquad A(z)=\frac{1}{2^n}\sum_x(-1)^{f(x)+x\cdot z}. \end{aligned}\]

The two factors of \(1/\sqrt{2^n}\), from preparation and the final Hadamards, account for \(1/2^n\). Since the target factors out in a normalized state, the probability of measuring input string \(z\) is \(|A(z)|^2\); we need not measure the target.

For \(z=0^n\), every dot product is zero. Let \(N_0\) and \(N_1\) count the inputs with outputs zero and one, respectively. Then

\[A(0^n)=\frac{N_0-N_1}{2^n},\qquad \Pr(0^n)=\left(\frac{N_0-N_1}{2^n}\right)^2.\]

If \(f(x)=c\) is constant, \(A(0^n)=(-1)^c\), so the all-zero outcome has probability one. Every other amplitude vanishes: for any nonzero \(z\), choose a position with \(z_j=1\) and pair each input \(x\) with the input obtained by flipping \(x_j\). Their dot products have opposite parity, so their contributions cancel. Consequently the final state is \((-1)^c\ket{0^n}\ket{-}\).

If \(f\) is balanced, \(N_0=N_1=2^{n-1}\), so \(A(0^n)=0\). The other outcomes carry total probability one. We therefore measure the input register once: the all-zero string means constant, and any string containing a one means balanced. A balanced function need not produce one particular nonzero string.

For a concrete calculation, take \(n=2\) and \(f(x_1,x_2)=x_1\oplus x_2\). In input order \(00,01,10,11\), the signs after the query are \((+1,-1,-1,+1)\), so the input state is \((\ket{00}-\ket{01}-\ket{10}+\ket{11})/2\). The final amplitudes are

\[\begin{aligned} A(00)&=(1-1-1+1)/4=0,\\ A(01)&=(1+1-1-1)/4=0,\\ A(10)&=(1-1+1-1)/4=0,\\ A(11)&=(1+1+1+1)/4=1. \end{aligned}\]

This particular balanced function therefore gives \(11\) with certainty. In contrast, \(f(x)=1\) gives the final input state \(-\ket{00}\), with the same measurement result as \(f(x)=0\).

The promise matters. If the function is neither constant nor balanced, the same probability formula still holds, but the decision rule no longer classifies it correctly. For example, \(f(x_1,x_2)=x_1x_2\) has \(N_0=3\) and \(N_1=1\), giving \(\Pr(00)=1/4\) even though it is not constant.

Under the promise, one quantum query suffices, with \(2n+1\) Hadamard gates outside the oracle. An exact deterministic classical algorithm needs \(2^{n-1}+1\) distinct queries in the worst case: after \(2^{n-1}\) identical answers, both a constant function and a balanced completion remain possible. This comparison requires certainty. A classical randomized procedure can sample \(k\) inputs independently and uniformly, declaring balanced if it sees both output values; on a balanced function, the probability of seeing only one value is \(2(1/2)^k=2^{1-k}\), for \(k\geq1\). Thus a fixed nonzero error tolerance needs only a number of classical queries independent of \(n\). Query counts also leave the cost of constructing the oracle unspecified; we turn to that cost next.

7.3.4 Constructing Boolean oracles§

So far we have specified what \(U_f\) does. Given the truth table of any Boolean function \(f:\{0,1\}^n\to\{0,1\}\), how can we build it? We must preserve the input and flip a target bit precisely when the table says one:

\[U_f\ket{x}\ket{y}=\ket{x}\ket{y\oplus f(x)}.\]

Begin with one row, say \(x=01\). A Toffoli gate flips its target when both controls are one. To make it recognize \(01\), first apply \(X\) to the first input wire, then apply the Toffoli controlled by both input wires, and finally undo the first \(X\). Only the original input \(01\) becomes \(11\) at the Toffoli; every input is restored afterwards.

For any row \(a=a_1\cdots a_n\), define the matching bit \(m_a(x)\) to be one if \(x=a\), and zero otherwise. Apply \(X\) to each input wire for which \(a_j=0\), apply a target flip controlled on all \(n\) inputs being one, and undo those input flips. Denote this row circuit by \(M_a\). It acts as

\[M_a\ket{x}\ket{y}=\ket{x}\ket{y\oplus m_a(x)},\qquad m_a(x)=\prod_{j=1}^n\begin{cases}x_j,&a_j=1,\\1-x_j,&a_j=0.\end{cases}\]

The product is one only when every bit matches the row. Now apply one such circuit for each row where \(f(a)=1\). For a fixed input, at most one row matches, so the combined target flip is exactly

\[\bigoplus_{a:\,f(a)=1}m_a(x)=f(x),\qquad \ket{x}\ket{y}\longmapsto\ket{x}\ket{y\oplus f(x)}.\]

The row circuits may be applied in any order because they restore the input and combine target flips by XOR. If there are no rows with output one, the oracle is the identity; if every row has output one, the whole construction simplifies to \(X\) on the target. For the balanced example \(f(x_1,x_2)=x_1\oplus x_2\), the marked rows are \(01\) and \(10\). Combining their row circuits gives the desired oracle, but the formula reveals a shorter implementation: a CNOT from \(x_1\) to the target followed by a CNOT from \(x_2\) to the target, giving \(y\mapsto y\oplus x_1\oplus x_2\).

The flip with \(n\) controls is itself a composite operation. For \(n=1\) it is a CNOT and for \(n=2\) a Toffoli. For \(n\geq3\), use \(n-2\) temporary qubits initialized to zero. Compute successive ANDs with Toffoli gates: \(w_1=x_1x_2\), then \(w_2=w_1x_3\), continuing to \(w_{n-2}=x_1\cdots x_{n-1}\). Flip the target with a Toffoli controlled by \(w_{n-2}\) and \(x_n\), then reverse the workspace computations. This uses \(2n-3\) Toffoli gates and restores all temporary qubits to zero. The same workspace can be reused for each row.

Each step is reversible and its basis-state action is exact, so by linearity the construction also works on superpositions. In particular, putting the target in \(\ket{-}\) makes this bit oracle implement the phase oracle:

\[U_f\left(\sum_x\alpha_x\ket{x}\ket{-}\right) =\left(\sum_x\alpha_x(-1)^{f(x)}\ket{x}\right)\ket{-}.\]

This construction requires no constant-or-balanced promise. It proves that every finite Boolean truth table can be implemented, but it can require up to \(2^n\) row circuits, each with work proportional to \(n\) in NOT and Toffoli gates. A compact formula for \(f\) can yield a much shorter reversible circuit, using the uncomputation of Section 7.1.4 to clear temporary results. In the query model, that circuit is supplied as a black box and one call counts as one query. If we must first read the entire truth table and synthesize the box ourselves, that work is an additional cost; the one-query Deutsch–Jozsa result does not remove it.
