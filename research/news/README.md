# News

`index.html` is the main article index. Keep individual article pages in this folder, for example `article-slug.html`.

To publish an article:

1. Create an HTML page in this folder using the shared site header, footer, and assets (`../../styles.css`, `../../script.js`, and `../../icons/`).
2. Add breadcrumbs for Home → Research → News → article title, with News linking to `index.html`.
3. Add a link, title, publication date, and short summary to the `news-list` in `index.html`, newest first. A commented HTML example is included there.
4. Remove the forthcoming notice when the first article is listed.

The index uses ordinary HTML links and works without JavaScript.
